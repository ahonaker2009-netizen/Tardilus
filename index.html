Gemini splits the text into questions and files them by chapter.

Format

  • # Category starts a top-level folder, ## Subfolder goes inside it, ### Folder inside that, and so on. Add a # for each level.
  • Or name the whole path on one line: # Derivatives > Chain Rule > Practice
  • Each question starts with 1., 1) or -, or is separated by a blank line.
  • Start a question with [test] to mark it as on the test, e.g. 1. [test] Differentiate sin(x^2).
  • Lettered parts like a) (b) c. or ii) always stay with the question above them, even with blank lines between parts.
  • Math: $...$, or just type dy/dx, ∂f/∂x, D/Dt.
  • Questions with no heading go to Uncategorized.
0 characters Long sets are sent in parts, so there is no size limit.
